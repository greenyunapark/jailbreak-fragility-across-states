# Dataset Notes

This directory contains evaluation artifacts used in the paper.

- `advbench_50.csv`: the 50-query AdvBench subset used in the main jailbreak
  experiments.
- `advbench_520_classified.csv`: AdvBench-520 queries with the harm-category
  annotations used in the scope analysis.
- `user_shared_prompts.csv`: the 15 user-shared system prompts analyzed in
  the paper.

The underlying benchmark and prompt sources remain subject to their original
licenses and terms. Please cite the original dataset releases when reusing
these files. The user-shared prompts were collected from the
`fka/awesome-chatgpt-prompts` dataset as described in the paper.
